# Gnomo

App para jugar a Gnomo con la baraja española desde un solo móvil, con opción de compartir la partida para que cada uno la siga en su móvil. Incluye el manual de reglas.

- `index.html`: la app (web estática, gnomo.onrender.com).
- `server/index.js`: servidor de salas para compartir partida (Node.js, sin dependencias, gnomo-salas.onrender.com).

Las tipografías Outfit y Alfa Slab One van incluidas en index.html bajo la licencia SIL Open Font License 1.1 (ver la carpeta fonts).
